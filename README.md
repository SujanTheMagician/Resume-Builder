## ✨ Features

- **Live Preview** — Resume updates in real-time as you type
- **4 Professional Templates** — Classic, Modern, Minimal, Creative
- **One-Click PDF** — Print-quality download, no watermarks
- **Social Links** — LinkedIn, GitHub, and Portfolio fields built in
- **No Account Needed** — All data stays in your browser
- **Dark UI** — Easy on the eyes while you craft your resume
- **Fully Responsive** — Works on desktop, tablet, and mobile

---

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/yourusername/resume-builder.git
cd resume-builder

# Install dependencies
npm install

# Start development server
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

## 📁 Project Structure

```
src/
├── Components/
│   ├── Intro/          # Landing & template selection
│   ├── Navbar/         # Navigation bar
│   ├── Footer/         # Footer
│   └── UserDataCollect/ # Resume form
├── Context/            # Global state (ResumeContext)
├── Pages/
│   ├── Home/           # Main page
│   ├── About/          # About the developer
│   └── Error/          # 404 page
└── Theme/
    ├── Theme1/         # Classic template
    ├── Theme2/         # Modern template
    ├── Theme3/         # Minimal template
    └── Theme4/         # Creative template
```
